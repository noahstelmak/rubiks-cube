# Rubik's Cube 

<img src="icon.png" alt="Image of a Rubik's cube" width="300">

A simple, interactive 3D Rubik's Cube simulator built with HTML, CSS, and JavaScript. This project showcases the use of transformation matrices to simulate the cube's rotations and animations, rendered using CSS.

Read this in other languages: [EN](README.md), [PT-BR](README.pt-br.md)

**Try it live at [GitHub Pages](https://noahstelmak.github.io/rubiks-cube/).**

## Features

- **Interactive Cube**: Rotate and manipulate a 3D Rubik's Cube in the browser.
- **Lightweight**: Pure JavaScript with no external dependencies.
- **Educational Tool**: Demonstrates how 3D transformations work in web development.

## How to Run the Project

Since the project relies on JavaScript and CSS, it needs to be served from a web server.

## Future Enhancements

- **WebGL Rendering**: Transition from CSS-based cube rendering to WebGL.
- **Solving Algorithms**: Implementing well-known Rubik's Cube solving algorithms.
- **Shuffle**: Add a random shuffle button.
- **Undo/Redo Functionality**: Add support for undoing and redoing moves to help users experiment and learn.
